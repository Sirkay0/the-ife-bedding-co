# The Ife Bedding Co. — E-Commerce Platform

A premium e-commerce web application for **The Ife Bedding Co.**, specializing in organic luxury bedding, mattresses, pillows, and home comfort essentials.

## 🎨 Brand Design System ("The Soft Earth")

The visual language is built upon organic tranquility and tactile earth tones:

### Color Palette
- **Cloud Dancer** (`#F7F5F0`): Main background canvas & studio product backdrops (60% Neutral Dominance).
- **Deep Espresso** (`#2B1D18`): Headings, primary text & structural contrast (30% Structural Contrast).
- **Warm Taupe** (`#8C7A70`): Secondary text, borders, placeholders & elevated framing.
- **Baked Clay** (`#C86B53`): Primary call-to-action buttons & conversion triggers (10% Intentional Accent).
- **Muted Sage** (`#98A892`): Trust badges, warranty tags & secondary actions.
- **Dusty Rose** (`#D4A5A5`): Sale prices, discount tags & hover highlights.

### Typography Hierarchy
- **Primary Headings**: `Playfair Display` (Serif)
  - **H1**: 48px, Semi-Bold
  - **H2**: 32px, Medium
- **Body & UI Controls**: `DM Sans` (Sans-Serif)
  - **Body**: 16px, Regular
  - **Small UI / Labels**: 14px, Medium

## 🛠️ Getting Started

First, run the development server:

```bash
pnpm dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 🚀 Tech Stack
- **Framework**: Next.js 16 (App Router with Turbopack)
- **Library**: React 19
- **Styling**: Tailwind CSS v4 & Vanilla CSS custom properties
- **Icons**: Lucide React
